## WallpaperEM v2.3.0

本次重点：**KDE Plasma 桌面正式适配** —— 装上 KDE 的 Linux 机器现在能识别会话类型、按能力分流（X11 / Wayland），并且给出了一条「动态壁纸 + 桌面图标两全」的路：把动态壁纸做成 **Plasma 壁纸插件**，在应用里**一键启用**。另外修掉了三个只在 Linux 装机后才暴露的问题（打包资源权限、手工构建漏 `custom-protocol`、托盘菜单不跟界面语言走）。
完整更新日志见 [CHANGELOG.md](https://github.com/oneincase/WallpaperEM/blob/v2.3.0/CHANGELOG.md)。

### 🚀 新特性

- **KDE Plasma 桌面适配**：新增 KDE 会话探测与能力路由（`XDG_CURRENT_DESKTOP` / `KDE_FULL_SESSION` / `XDG_SESSION_TYPE`），按「X11 = 桌面层语义可用 / Wayland = 只走后端能力」分流；配套 KWin / Plasma 后端：窗口规则文件合并与回滚、KScreen 每屏查询、`ScreenSaver` 空闲检测、模糊协议迁移到 `ext_background_effect_manager_v1`（新协议优先、旧协议回退，X11 原子路径不变）。KDE 静态壁纸改为三级回退：`org.freedesktop.impl.portal.Wallpaper`（Plasma 6.5+）→ `plasma-apply-wallpaperimage` → `qdbus … evaluateScript`。
- **应用内「一键启用 KDE 插件」**（设置 → 通用 → KDE 集成，仅 Linux 显示）：一个按钮把 Plasma 壁纸插件装进 `~/.local/share/plasma/wallpapers/`、把桌面壁纸切成它、并接上引擎侧帧导出；关掉时还原你原来的壁纸（记住切换前的选择），插件包保留。需要先有一张正在播放的动态壁纸。
- **引擎侧帧导出（`frame_export`）**：把正在播放的画面以 X11 窗口抓帧写成 PPM + 序号文件（`/dev/shm/wallpaperem`），供 Plasma 插件读取显示；插件模式下引擎窗口保持映射但整窗透明（隐藏会让页面动画停摆）。
- **KDE 桌面图标取舍的启动提示**：桌面是「文件夹视图」时启动写一条警告，如实说明动态壁纸会盖住桌面图标、以及怎么改成「桌面」布局（只读判定，不改你的配置）。
- **`webwallgl` 渲染库改走 npm 依赖（3.0.0）**：此前是同级目录的 `file:` 依赖，现在从 registry 装，检出仓库即可构建。

### 🛠 修复

- **界面切成中文后，托盘菜单还是英文**（两层原因）：① 界面语言从来没推给后端，后端一路沿用系统语言兜底；② 即使推了，Linux（GTK 后端）上子菜单标题的文字改不动 —— 现在改为**整份重建菜单**，`轮播 / 显示器 / 画质档位 / 滤镜效果 / 切换效果` 也会跟着语言走；同时把语言记进数据库，**下次启动第一帧就是对的**。
- **装到系统里打开主窗口显示 `Could not connect to localhost: Connection refused`**：手工构建漏了 `--features tauri/custom-protocol`，产物是开发模式二进制（会去连 Vite 开发服务器）。官方 `pnpm tauri build` / CI 出的包不受影响。
- **插件包曾以 `0600` 权限打进 deb，装机后「一键启用」必然失败**（普通用户读不到包里的文件）：同步脚本与打包 staging 都做了权限归一，CI 也加了断言。
- **KDE 静态壁纸失败后不再无法回退**（`plasma-apply-wallpaperimage` 与 `qdbus evaluateScript` 两条路各自独立）。
- **快捷键在 KDE Wayland 下不再静默失败**：标记为「由桌面接管」并在界面上说明。
- **自动暂停的「前台应用」判据在 KDE/X11 上真正生效**：从恒 `Unknown` 改为读 EWMH 活动窗口并分类（桌面/面板 = 播放、自己 = 播放、别的应用 = 暂停）。
- **Linux 托盘图标改用彩色图标**：原来用的那张是纯黑剪影，深色面板上不可辨。
- **KDE 分支新增的 77 条后端文案补上英文**（此前只露中文）。
