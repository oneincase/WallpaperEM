## WallpaperEM v2.2.0

本次重点：**WE 编辑器源码工程免打包直接渲染**——官方示例工程这类散装目录（`project.json` 指向 `.json` 入口、资源散在各子目录）现在可以直接导入当壁纸，另外视频渲染路径开放了「画布」兼容备用档，并同步了 webwallgl 2.1.0 引擎的一整批修复。
完整更新日志见 [CHANGELOG.md](https://github.com/oneincase/WallpaperEM/blob/v2.2.0/CHANGELOG.md)。

### 🚀 新特性

- **松散目录形态（webwallgl 2.1.0）**：不再强制要求 `scene.pkg`。WE 编辑器的 `defaultprojects` / `myprojects` 源码工程（`project.json` 的 `file` 指向 `scene.json` / `techno.json` 这类入口、资源散在 `materials/` `shaders/` `models/` 等子目录）用「添加壁纸路径导入」选目录即可入库直用。声明了 pkg 入口但盘上只有 pkg 的工坊条目照常渲染（自动回退），行为无变化。
- **视频渲染方式可切换**（设置 → 播放）：硬解直通（默认，解码帧零拷贝上屏，最流畅省电）/ 画布（每帧绘入 canvas 再合成，兼容备用）。切换后正在播放的视频壁纸自动重挂。实测滤镜对直通路径零 CPU 成本，旧的「滤镜与直通互斥」限制已废除。

### 🛠 修复

- **路径导入识别**：`project.json` 省略 `type` 字段的工程（techno、audiophile 等）不再被误判成图片类型。
- **未知类型不再白屏**：前端类型表补全 `image`，类型标签渲染加兜底。

### ⚙️ 引擎更新（webwallgl 2.1.0，随包自动生效）

- 源码工程装载链与官方示例全量兼容（F1–F50 判据体系）
- 场景级相机路径、`usershadervalues` 绑定
- 渲染修复：混合 pass 不写深度（neon_sunset 太阳外围黑方块）、真 3D 模型帧内共享深度与透明像素不写深度（模型互相盖住 / 树黑方块）、`anchor:none` 文字按对齐贴 origin（文字时钟被蒙版抹掉）
- 兼容修复：`applyUserProperties` 按官方字母序下发（corsair_collection 白屏）
- 稳定性：GPU 资源确定性归零、WebGL 上下文丢失从静默冻结变成可见事件、畸形 `.tex` 不再拖垮解析器
- 性能：重粒子场景稳态帧率 +15.2%
