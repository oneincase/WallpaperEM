## WallpaperEM v2.1.1

本次重点：修复 **macOS 打包版读不到系统「正在播放」**（封面 / 歌名 / 艺人 / 进度全空）—— v2.1.0 的 macOS 包在 macOS 15.4 及以上受影响。
完整更新日志见 [CHANGELOG.md](https://github.com/oneincase/WallpaperEM/blob/v2.1.1/CHANGELOG.md)。

### 🐛 主要修复

- **macOS 打包版读不到系统「正在播放」**：表现为正在播放的封面、歌名、艺人、进度都是空的，而播放控制按钮也不生效。原因是 macOS 15.4 起系统收紧了 MediaRemote 的读取权限，只有「被授权」的进程能读到数据；本软件要靠一段随主程序分发的权限通道组件（由系统自带的 `perl` 代读）绕开这个限制。打包时该组件**没有真正被编进主程序**——构建脚本在带 `--target` 的构建（macOS 通用包必然带）下找不到它，而找不到时它只是静默跳过，运行时退回直连、在 15.4+ 上永远读到空数据，从界面上也看不出任何报错。本版把它按两个架构各编一份、合并后显式指给构建，并新增**构建期断言**：产物每个架构切片里必须真的带着该组件，否则直接让构建失败，坏包不会再发出去。
- **影响范围**：仅 macOS 15.4 及以上的打包版；Windows / Linux 与 macOS 15.3 及以下不受影响（这些平台上直连可用或走别的读取路径）。
- **已装 v2.1.0 的 macOS 用户**：升级后即可恢复（正在播放的壁纸、封面与播放控制都会回来）。

### 📦 下载

- **macOS**：`WallpaperEM_2.1.1_universal.dmg`（Apple Silicon + Intel；自签名证书、未公证，首次打开如被拦下请在「系统设置 → 隐私与安全性」放行）
- **Windows x64**：`WallpaperEM_2.1.1_x64-setup.exe`（NSIS）或 `WallpaperEM_2.1.1_x64_en-US.msi`
- **Windows ARM64**：`WallpaperEM_2.1.1_arm64-setup.exe`（NSIS）或 `WallpaperEM_2.1.1_arm64_en-US.msi`
- **Linux x64**：`WallpaperEM_2.1.1_amd64.deb` / `WallpaperEM_2.1.1_amd64.AppImage`
- **Linux ARM64**：`WallpaperEM_2.1.1_arm64.deb` / `WallpaperEM_2.1.1_aarch64.AppImage`

已装旧版的用户可在「设置 → 关于 → 软件更新」里检查更新并直接升级。
