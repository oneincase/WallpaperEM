## WallpaperEM v2.1.0

本次重点：多显示器每屏独立设置、插件生态（插件页 / 插件市场 / 接入协议 v1）、可切换的下载工具，以及视频壁纸硬解直通。
完整更新日志见 [CHANGELOG.md](https://github.com/oneincase/WallpaperEM/blob/v2.1.0/CHANGELOG.md)。

### ✨ 主要新功能

- **多显示器每屏独立设置 + 托盘「显示器」菜单**：手动给某块屏设壁纸只影响那块屏并把它「钉住」，统一轮播列表从此不刷它；每屏也可绑自己的轮播列表。托盘新增「显示器」子菜单（每屏：当前壁纸 / 壁纸设置 / 轮播列表 / 清除壁纸），壁纸设置窗按光标所在屏打开。
- **插件页 + 插件市场 + 第一个内置插件 DeepSeek Harness**：胶囊导航新增「插件」，插件分内置 / 第三方；第三方插件是**声明式清单**（只描述名称、图标与一个入口，不是可执行代码），装、卸、往目录里手放一份都即时生效；市场以 GitHub `topic:wem-plugin` 仓库搜索为来源。内置 dsh 插件自动扫描本机 `dsh`，没有就摊开安装引导，随后用干净 profile 起一个带 MCP 的 harness。
- **第三方插件接入协议 v1**：`schemaVersion` / `capabilities` 能力白名单 / `minAppVersion` / id 冲突规则 / 错误码表，配套 JSON Schema 与可直接复制的作者模板（含 CI 自查脚本）。
- **下载工具可切换：新增 DepotDownloader 后端（默认仍是 steamcmd）**：设置 →「账号」里可选，按需从上游官方 Releases 安装、不随应用分发；逐文件百分比进度，用令牌登录、不挤掉正在运行的 Steam 客户端。
- **视频壁纸改走硬解直通**：VideoToolbox 解出的帧零拷贝交给窗口合成器，去掉每帧几十 MB 的纹理上传 —— 4K 视频壁纸掉帧的根因消除。
- **本地库批量操作**：多选后支持批量「移除」（只清库记录、文件留在磁盘）与批量「删除」（连文件删）；卡片新增「壁纸属性 / 壁纸信息 / 移除壁纸」入口。
- **MCP 场景创作能力扩容**（面向 AI / Agent 创作）：离屏预览（不碰桌面）、三平台抓帧、多帧截图、渲染器诊断历史、工程结构化体检、图层「到底画出来没有」自检、逐像素 A/B 对比、粒子与 shader 脚手架，以及三份机器可读的参考资源。

### 🛠 主要改变

- **「应用到哪块屏」收进显示器坞**：多屏时先在坞里点卡片锁定目标屏（应用失败不消耗锁定），不锁定 = 全部显示器；「应用到桌面」菜单里正在播放的屏可再点一次就地停止。
- **无壁纸态按平台材质可用性兜底**：窗口材质真落地时保持磨砂玻璃观感，否则垫一层等效约 70% 不透明的深底，保住白字可读性。
- 本地库「类型」筛选的「预设」改为「项目」（本软件自建工程），MCP `library_list` 与界面同源。

### 🐛 主要修复

- **多屏轮播**：手动应用不再解掉用户显式暂停的轮播；「清空壁纸」与删列表全量收口；所有屏都被单独设置时统一列表正确显示「未在轮播」。
- **用户显式「停止」过的屏不再自己复活**（含重启与显示器 id 迁移）。
- **macOS 多屏几何**：副屏与主屏高度不等时壁纸窗不再露边。
- **DepotDownloader 登录态真正落在应用目录、登出真能清掉**（macOS `CFFIXED_USER_HOME`、Windows 按时间窗清扫），登录态标记不再撒谎。
- **关掉 dsh 插件后不再留下看不见的 node**（子进程按进程组收尾，启动时回收孤儿实例）。
- 另修：同名 `.tex` 静默顶掉源图、MCP 写大贴图被 2 MB 请求体静默打回、改完工程截图仍是旧画面等。

### 📦 下载

- **macOS**：`WallpaperEM_2.1.0_universal.dmg`（Apple Silicon + Intel；自签名证书、未公证，首次打开如被拦下请在「系统设置 → 隐私与安全性」放行）
- **Windows x64**：`WallpaperEM_2.1.0_x64-setup.exe`（NSIS）或 `WallpaperEM_2.1.0_x64_en-US.msi`
- **Windows ARM64**：`WallpaperEM_2.1.0_arm64-setup.exe`（NSIS）或 `WallpaperEM_2.1.0_arm64_en-US.msi`
- **Linux x64**：`WallpaperEM_2.1.0_amd64.deb` / `WallpaperEM_2.1.0_amd64.AppImage`
- **Linux ARM64**：`WallpaperEM_2.1.0_arm64.deb` / `WallpaperEM_2.1.0_aarch64.AppImage`

已装旧版的用户可在「设置 → 关于 → 软件更新」里检查更新并直接升级。
